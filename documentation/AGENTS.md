# Instrucciones para agentes

Antes de modificar código:

1. Revisar documentación.
2. Mantener la arquitectura existente.
3. No instalar dependencias sin justificar.
4. Mantener TypeScript estricto.
5. Ejecutar npm run lint antes de finalizar.

Al finalizar cada sección o tarea de desarrollo:

6. Identificar tareas pendientes o futuras surgidas durante el trabajo.
7. Agregarlas al archivo `documentation/08_tareas_pendientes.md`.
